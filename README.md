# Ashwood Forge

A fully static, 5-page website for a fictional bladesmithing and
blacksmithing workshop — built as a university web development project.

**No backend, no database, no framework.** Just HTML, CSS and
JavaScript, viewable by opening `index.html` in any browser.

## Live pages

| Page | File | What's on it |
|---|---|---|
| Home | `index.html` | Hero banner, highlights, featured-work carousel |
| About | `about.html` | Studio story, 4-step process, values, team table |
| Services | `services.html` | Service cards, pricing table, FAQ accordion |
| Gallery | `gallery.html` | Filterable image grid with a lightbox popup |
| Contact | `contact.html` | Validated contact form, info table, embedded map |

## Tech used

- **HTML5** — semantic tags (`header`, `nav`, `main`, `section`, `footer`, `figure`, `table`, `form`, etc.)
- **CSS3** — one stylesheet (`css/style.css`), CSS custom properties for a consistent colour/type system, Flexbox + Grid layout, responsive breakpoints for tablet and mobile
- **Vanilla JavaScript** — no framework or library. Five interactive features: a hamburger nav menu, an image carousel, gallery filtering with a lightbox, an FAQ accordion, and client-side form validation
